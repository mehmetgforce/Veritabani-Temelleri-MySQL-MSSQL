# Veritabani-Temelleri-MySQL-MSSQL
MySQL ve MS SQL Server üzerinde gerçekleştirdiğim temel veritabanı (RDBMS) pratiklerini içeren bir projedir. 'Okul' veritabanı ve 'Ogrenciler' tablosu üzerinde; veri ekleme, listeleme, güncelleme ve silme (CRUD) işlemlerini MySQL ve T-SQL dillerinde uyguladım. Yazılım mühendisliği temellerine dair SQL scriptleri ve çalışma mantıklarını içerir.
